# Sadoon · Personal Brand

الموقع الشخصي لسعدون (سعيد إسماعيل)، محرر فيديو.
موقع ثابت (HTML/CSS/JS) بالعربية والإنجليزية، بدون أي خطوات بناء.

## الأقسام
الهيرو · من أنا · كيف أبني فيلمك · أعمال مختارة + كل الأعمال · الخدمات · التدريب الشخصي · أكاديمية سعدون فيلم · التواصل

## التعديل السريع
في أعلى السكربت داخل `index.html`:
- `GATEWAY_URL`: رابط أكاديمية سعدون فيلم.
- `WA`: رقم واتساب.
- `FEATURED`: الأعمال المختارة الثلاثة.
- مصفوفة `P`: الأعمال وروابطها (درايف / Vimeo / Behance).
- كائن `EN`: النصوص الإنجليزية.

## النشر
متصل بـ Vercel: أي push على `main` يُنشر تلقائياً.
